No hay compra ficticia habilitada.

Archivos: app (páginas públicas, estilos, layout y API auth), components, lib/{auth,auth-options,auth-client,catalog,cart}, scripts/{auth-schema,init-auth-env}, db/migrations/001-auth.sql, tests/{store.test.mjs,auth-integration.mjs}, package.json, pnpm-lock.yaml y .env.example.
